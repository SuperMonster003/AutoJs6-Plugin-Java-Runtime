# v0.8.0

# v0.8.0-m9

###### 2026/08/27

* `提示` 会话默认超时 30 秒, 上限 120 秒, 同时仅允许一个会话 (额外会话返回可重试的 BUSY)
* `提示` ECJ 升级评估结论: 新版 ECJ (3.42/3.46) 无法在 Android 运行, 正式线继续固定 ECJ 3.26.0 与 Java 8
* `新增` Protocol 1.6 多文件源码包, 单次支持 2 至 32 个 .java 文件, 路径须与包名一致
* `新增` 自定义入口类简名, 支持 ASCII 名称 (默认为 Main), 并提供 arbitrary-entry.java 示例
* `优化` 明确 Kotlin/JVM 支持由姊妹插件 Kotlin Runtime 独立承担; 两仓共享冻结协议与一致性测试, 不建立运行依赖
* `依赖` 升级运行时 D8/R8 版本 8.13.17 -> 8.13.23, 同步更新编译缓存

# v0.7.0-m9

###### 2026/08/26

* `提示` 观测数据不含源码, 参数, 路径或进程身份; Release 构建不导出累计缓存计数
* `新增` Protocol 1.5 执行摘要, 回传编译, 执行及清理耗时, 缓存命中, 冷暖启动和资源采样信息

# v0.6.0-m9

###### 2026/08/26

* `新增` Protocol 1.4 运行时异常信息, 回传脱敏类名及源码行 (java/javax 以外的类显示为 UserException, 不传递异常消息及完整堆栈)
* `新增` 运行时异常示例 `runtime-exception.java`, 演示用户可见的"类名 + 行号"形态

# v0.5.0-m9

###### 2026/08/25

* `提示` 脚本参数仅接受 JSON 兼容值, POJO 或 Android 对象返回 JVM_SOURCE_INVALID_ARGUMENTS
* `新增` 脚本入参 (Protocol 1.3 / Entry API 4): `context.args()` 返回宿主执行配置的只读参数快照 (上限 64 KiB, 深度 64); 既有无参脚本无需修改即可继续运行
* `新增` 脚本入参示例 `script-args.java`, 演示读取嵌套 Map/List/布尔/数字/字符串与 null

# v0.4.0-m9

###### 2026/08/25

* `提示` Android 10 及以上系统调用剪贴板时, AutoJs6 必须处于前台 (存在 resumed Activity); 后台调用会在触碰系统剪贴板前稳定失败
* `新增` 剪贴板能力 (Protocol 1.2 / Entry API 3): `clipboard().getText/setText`, 读与写为两项独立授权, 文本上限 16 KiB
* `新增` 多 DEX 编译产物, 支持 1 至 4 个连续编号文件, 总大小上限为 32 MiB (API 26 因系统限制仅支持单 DEX)
* `新增` 核心库脱糖, Android 7.0+ 可使用 java.time 及 Stream.iterate/toList 等接口, 不支持的方法在编译时报告
* `新增` 中文"Java Context API 与运行边界"文档: 全部方法说明, 返回值类型表, 资源上限与错误码语义
* `新增` 取消, 返回值家族, 编译错误与结果超限等示例矩阵 (真机验证), 以及一键离线验证脚本 `scripts/verify.ps1` / verify.sh
* `修复` 编译错误脱敏时丢失整条编译器消息的问题, 改为仅替换敏感片段
* `修复` 编译缓存通道超时后永久失效的问题, 支持冷却后恢复
* `优化` 一次编译的多条 ECJ 错误按源码顺序逐条回传 (共用 64 KiB 诊断预算)
* `优化` Debug 构建的私有执行诊断, 支持阶段耗时, 工作进程冷启动及缓存计数 (Release 构建不导出)
* `优化` 补充 Android 7/16 的执行性能及预热评估, 保留串行执行, 插件端支持自定义入口类名
* `优化` 明确编译缓存仅在编译器进程内有效, 不提供持久化缓存
